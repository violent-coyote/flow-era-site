# flow-era-site

The public Flow Era page, served by GitHub Pages at https://violent-coyote.github.io/flow-era-site/ .
Plain HTML, no build step.

- `index.html`: one page, links to itch.io and Steam.
- `privacy.html`, `terms.html`: policy pages for the social-posting apps (TikTok, YouTube).
- `oauth/tiktok.html`: static OAuth redirect target. Shows the `code` query parameter for copy and paste
  into the auth script; it makes no network calls.
- `assets/`: the Flow Era icon.

Every page credits Flow Era, nothing else.
