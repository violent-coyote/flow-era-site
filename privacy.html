Flow Era

Privacy Policy

Effective 2026-10-17

This policy covers the Flow Era website and the Flow Era Publisher application. Flow Era Publisher is an internal tool that publishes Flow Era's own gameplay videos to Flow Era's own social media accounts, including TikTok and YouTube. It is used only by Flow Era. It is not offered to the public, and no one outside Flow Era can sign in to it.

What we collect

Nothing from visitors. This website sets no cookies, runs no analytics, and makes no network requests other than loading its own pages.

When Flow Era signs in to a social platform through Flow Era Publisher, that platform issues an OAuth access token and refresh token for Flow Era's own account. Those tokens, and the basic profile information the platform returns for that account (such as display name and avatar), are the only data the application handles.

How we store it

OAuth tokens are stored only as encrypted secrets in GitHub Actions. They are never written to a file in a repository, never logged, and never shared. The videos the application posts are Flow Era's own game footage.

Third parties

We do not sell, share, or transfer any data to third parties. The only services that receive data are the social platforms the application posts to, and only the data needed to publish a video to Flow Era's own account on that platform.

Deleting data

Flow Era can revoke the application's access at any time from the platform's connected-apps settings, which invalidates the stored tokens. To ask about any data, email cm@crabonfire.com.

Changes

If this policy changes, the new version is published at this address with a new effective date.
